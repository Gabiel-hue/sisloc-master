Como usar o rollback

1. Clique em 🚀 Gravar Regras + Changelog normalmente.
2. Após o sucesso, o botão fica laranja: ↩ Desfazer gravação.
3. Se quiser desfazer, clique nele → confirma com Sim, desfazer.
4. Pronto, o requisito volta ao estado anterior e o botão volta a permitir Gravar.

Mesma coisa para o botão 🔗 Atualizar links na demanda → vira ↩ Desfazer atualização de links.

Atenção: o rollback expira ao fechar/recarregar a página. Se alguém editou manualmente o requisito/demanda entre o gravar e o desfazer, o Sisloc Master detecta e mostra erro explicando.
